Project 1: Colorizing Images

William Wu · CS 180

1. Method

I split each scan into blue, green, and red channels. I keep blue fixed, align green and red to it, and combine the channels into an RGB image.

Single scale: I test shifts from −30 to +30 pixels in both directions and choose the smallest L2 error: the square root of the sum of squared pixel differences. I convert values to floats in [0, 1] and ignore a 10% border on each side when scoring.

Image pyramid: I blur and halve the images until the longest side is at most 256 pixels. I search ±30 pixels at this size, double the estimated shift at each larger size, and search ±2 pixels around it. This handles large shifts without a wide search at full resolution. The final color image uses the original channels.

3. Edge improvement

The same object can have different brightness in each color channel. Raw-pixel matching left Church and Emir misaligned.

I use Sobel filters to measure horizontal and vertical brightness changes. Combining them as √(dx² + dy²) gives an edge-strength image. I compare edge maps at each pyramid level using mean squared error, then apply the selected shifts to the original color channels.

This version also scores only overlapping interior pixels, excluding wrapped pixels. It uses the same search settings for every image.
